    How QRShield decides

    Every scan is checked against on-device rules only: link structure, lookalike domains, link-shorteners that hide a destination, insecure connections, unusual characters, and QR types that carry sensitive data (Wi-Fi passwords, contact cards, one-time-passcode secrets). Each result also shows a confidence percentage — how far the evidence sits from a borderline call, not a guarantee. Nothing is uploaded, and no destination link is ever opened automatically. This is a heuristic check, not a database of known threats — always be cautious with codes from untrusted sources.

    How Safe Preview protects you

    Safe Preview never lets your device touch the destination. When you tap it, a public anonymizing relay fetches the page instead — so the site sees the relay's IP address, not yours, and receives no cookies, no referrer, and nothing that identifies you. What comes back is shown as plain, script-free text: nothing from the page can run, load images, or make network requests here. Honest fine print: the relay service itself does see the link you're previewing (that's how it fetches it) — previews only happen when you tap the button, never automatically.

    What's new in 13.46

    • Safe Preview — read a link's page through an anonymous relay before opening it. No IP, no cookies, no scripts.
    • Link X-Ray — every result can break the address into scheme, host, path and each decoded parameter, with flags.
    • Tracker stripping & HTTPS upgrade — links open cleaned of personal identifiers, encrypted when possible.
    • Paste to check — analyze any link or text without scanning a code.
    • Share results and a hardened app: a strict Content-Security-Policy now blocks every unexpected network destination.
